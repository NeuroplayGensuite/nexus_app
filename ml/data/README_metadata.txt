NeuroGen Suite -- SYNTHETIC dataset generation metadata
=========================================================
Random seed: 42
Rows per dataset: 6000

IMPORTANT: All risk_group labels are SYNTHETIC, generated by a latent-variable
process with heavy class overlap for ML-pipeline development/testing only.
They carry no clinical or diagnostic meaning and were not derived from any
real participant's actual disorder status. The real gameplay sample supplied
alongside this task was used only to inform realistic feature ranges/scales
(e.g. maze mse/jerk/tremor magnitudes, cricket response-time scale, sync
accuracy scale, star per-round accuracy decay pattern), not to assign labels.

Files:
- dyslexia_dataset.csv    (Phonic Finder)
- dysgraphia_dataset.csv  (Maze)
- dyscalculia_dataset.csv (Cricket Forge)
- dyspraxia_dataset.csv   (Sync Master)
- nvld_dataset.csv        (Star Mapper)

Universal CV block (all files): faceDetectedRatio, onScreenEngagementRatio,
lookingAwayEvents, totalLookingAwayDurationMs, averageLookingAwayDurationMs,
trackingDurationMs, cameraAvailable. ~14% of rows have cameraAvailable=False,
in which case all other CV fields are null (missing), never zero.
